# MEMETEK Website

A responsive, single-page MEMETEK community website built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required.

## Included
- `index.html` — page structure and content
- `style.css` — responsive black, white, and yellow theme
- `script.js` — mobile navigation, current year, and reveal effects
- `assets/memetek-logo.png` — supplied MEMETEK logo
